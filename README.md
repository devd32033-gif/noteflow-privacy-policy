# NoteFlow - Beautiful Note Taking App

NoteFlow is a modern, beautiful note-taking application with gradient color themes, local storage, and Firebase synchronization. It allows users to create, edit, and organize notes with a visually appealing interface.

## Features

- 🎨 Beautiful gradient color themes for notes
- 📝 Create text notes and link notes
- 💾 Local storage using Room database
- 🔗 Automatic link detection and opening
- ☁️ Firebase synchronization when online
- 🔍 Search functionality
- 📌 Pin important notes
- 🌙 Dark mode support

## Tech Stack

- **Kotlin** - Primary programming language
- **Jetpack Compose** - Modern UI toolkit
- **Room Database** - Local data storage
- **Firebase** - Cloud synchronization
- **MVVM Architecture** - Clean separation of concerns
- **Navigation Component** - Screen navigation
